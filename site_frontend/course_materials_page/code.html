Course Syllabus

Weekly slides, notes, and resources.

This week, we dive deep into non-linear data structures, focusing primarily on Trees and Graphs. We will cover implementation details in Python and explore common traversal algorithms (BFS, DFS) essential for technical interviews.

Learning Objectives

  • check_circle Understand the properties of Binary Search Trees (BST).
  • check_circle Implement Depth-First Search (DFS) iteratively and recursively.
  • check_circle Analyze the time complexity of graph traversal algorithms.
  • check_circle Apply Dijkstra's algorithm to find shortest paths.

A comprehensive review of classic sorting algorithms (Merge Sort, Quick Sort, Heap Sort) and their performance characteristics. We also covered binary search variations.

Learning Objectives

  • check_circle Implement O(n log n) sorting algorithms.
  • check_circle Understand stable vs. unstable sorting.

Introduction to linear data structures. We built dynamic arrays, linked lists, and used them to implement stack and queue abstractions.
