My Story

Hi, I'm Alex. I'm a passionate front-end developer currently navigating my final year in the Computer Science program. I've always been fascinated by the intersection of design and engineering—how a clean interface can simplify complex technical systems.

Over the past two years, I've focused heavily on building accessible, high-performance web applications. My tool of choice is React, but I'm currently diving deep into web shaders and performance optimization techniques.

When I'm not coding, you can usually find me contributing to open-source UI libraries, reading up on the latest design system trends, or trying out new coffee roasts while debugging obscure CSS issues.
